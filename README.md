# 📊 Sales Dashboard – Power BI Project  

This project presents an **interactive Sales Analysis Dashboard** built using **Power BI Desktop**.  
The dashboard provides a clear overview of key business metrics, visualizing sales trends, customer behavior, and profit performance across different segments.

---

## 📁 Project Files
- **Sales_Dashboard.pbix** – Power BI project file  
- **sales_dashboard_project.pdf** – Exported dashboard for quick viewing  

---

## 🔍 Key Insights from the Dashboard

### 📌 Overall KPIs
- **Total Sales:** ₹1.6M  
- **Total Profit:** ₹175K  
- **Total Quantity Sold:** 22K  
- **Average Delivery Days:** 10 Days  

---

### 📌 Sales Analysis
- Highest revenue generated in **Technology** and **Office Supplies** categories.  
- **Phones** is the top-performing sub-category.  
- Monthly sales show clear fluctuations between **2019–2020**, identifying high-performing months.

---

### 📌 Customer Segment Insights
- **Consumer** segment contributes maximum sales.  
- Corporate and Home Office segments show consistent but lower volumes.

---

### 📌 State-Wise Performance
- Top revenue-generating states are highlighted using a filled map visual.  
- Profit distribution varies sharply across regions, revealing opportunities for improvement.

---

### 📌 Payment Mode Insights
- Highest transactions recorded via **COD** and **Online payments**.  
- Card payments show moderate usage.

---
